자주 묻는 질문

궁금한 점을 빠르게 찾아보세요. 추가 문의는 1:1 문의를 이용해주세요.

리뷰어 (체험단 신청자)
온종일 체험단은 어떻게 신청하나요? +
회원가입 후 원하는 캠페인 페이지에서 [신청하기] 버튼을 클릭하면 됩니다. 신청 시 채널 URL과 팔로워/방문자 정보가 자동 첨부되며, 마감일 이후 2영업일 내에 선정 결과를 이메일로 안내해드립니다.
체험단 선정 기준은 무엇인가요? +
팔로워 수, 블로그 일방문자 수, 이전 리뷰 완료율, 콘텐츠 품질 등을 종합 평가합니다. 단순히 팔로워가 많은 계정보다 꾸준히 활동하고 완료율이 높은 리뷰어를 우선 선정합니다.
리뷰 제출 기한을 넘기면 어떻게 되나요? +
방문일 기준 7일 이내에 리뷰를 제출해야 합니다. 기한 내 미제출 시 '미완료' 처리되며, 미완료 누적 시 신청이 제한될 수 있습니다. 불가피한 사정이 있는 경우 고객센터로 미리 연락해주세요.
원고료는 언제 지급되나요? +
원고료 지급 캠페인의 경우, 리뷰 URL 제출 후 검수 완료(보통 2-3영업일)부터 영업일 기준 5일 이내에 등록하신 계좌로 입금됩니다.
채널이 여러 개인 경우 모두 등록할 수 있나요? +
네, 블로그·인스타·유튜브·네이버 클립 등 여러 채널을 마이페이지에서 등록할 수 있습니다. 각 캠페인별로 요구하는 채널이 다르니 등록 시 확인해주세요.
광고주 (사장님)
캠페인 등록 비용은 얼마인가요? +
스타터 플랜 월 49,900원부터 시작합니다. 플랜에 따라 동시 운영 캠페인 수, 모집 인원 한도, 노출 우선순위가 달라집니다. 광고주 페이지에서 자세한 요금표를 확인하세요.
체험단 리뷰어 선정은 누가 하나요? +
기본적으로 온종일 체험단 시스템이 자동으로 적합한 리뷰어를 선정합니다. 그로스 이상 플랜 사용 시 사장님이 신청자 목록을 직접 확인하고 선정하는 기능을 사용하실 수 있습니다.
리뷰가 마음에 들지 않으면 삭제 요청이 가능한가요? +
체험단 리뷰는 실제 경험에 기반한 콘텐츠로, 단순히 마음에 들지 않는다는 이유로는 삭제 요청이 어렵습니다. 단, 허위 사실·욕설 등 계약 조건 위반 내용은 고객센터를 통해 이의 제기가 가능합니다.
등록한 캠페인을 중간에 수정할 수 있나요? +
모집 기간 중에는 일부 항목(모집 인원, 방문 가능 기간 등) 수정이 가능합니다. 단, 혜택 내용과 리뷰 조건은 선정 후 변경이 제한될 수 있습니다. 관리자 페이지에서 직접 수정하시거나 고객센터에 문의해주세요.
