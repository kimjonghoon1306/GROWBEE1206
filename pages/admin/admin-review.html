신청중회원이 캠페인에 신청만 한 상태. 아직 뽑히지 않음. 선정됨관리자가 체험단으로 뽑은 상태. 이제 회원이 방문·리뷰 작성. 리뷰 제출됨회원이 리뷰 링크를 제출한 상태. 검수 대기 중. 검수완료리뷰 확인 완료 → 포인트 지급됨. 광고주가 볼 수 있음.
버튼 뜻
선정 = 신청자를 체험단으로 뽑기  ·  탈락 = 신청자를 안 뽑기(미선정)  ·  검수완료 = 제출된 리뷰 승인+포인트지급  ·  반려 = 리뷰가 미흡해 다시 쓰라고 돌려보내기(선정 상태로)
※ 리뷰는 자동으로 검사돼서 통과하면 바로 '리뷰 제출됨'이 돼요. 자동검사가 틀렸다며 회원이 재검토를 요청하면 여기서 승인/거절로 처리합니다.
